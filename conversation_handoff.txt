UPDATE — OCTOBER 9, 2026: GEOREFERENCER AND PERFORMANCE

- index.html now supports official David Rumsey Georeferencer XYZ exports through rumsey-georeferencer.js. If an entry has georeferencerTiles, the app prefers that single tiled raster source over the older Google Earth/KML-derived local fallback.
- The current Georeferencer requires a signed-in user to generate each map's GIS export URL and access key. Those per-map export URLs were not available in this workspace, so rumsey-georeferencer.js is currently an empty configuration template. Populate it with URLs copied from “Use in GIS apps” on each official Georeferencer map page.
- Main-map credits now link to the David Rumsey record or official Georeferencer rather than to the old Google Earth KML.
- The local fallback no longer creates every image layer at once. It loads only image rectangles intersecting the current viewport and refreshes them after the map finishes moving. This addresses the main rendering bottleneck: some maps previously created 50–63 independent raster/image layers at once.
- The local cache contains 2,063 preview images totaling about 129 MB. Individual heavy selections were about 1–7 MB, but the number of simultaneous GPU textures/layers was the bigger problem.
- The app now reports historical-overlay download failures in the overlay credit and explicitly reports WebGL context loss as a graphics-processor failure. A weak computer can make the heavy maps slow, but a map that never appears is generally a source/loading failure rather than ordinary slowness.
